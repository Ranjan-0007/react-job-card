# React Components & Props Project

## 📌 Project Description
This is a beginner-friendly React project created to understand and practice
**React Components** and **Props**.

The project demonstrates how reusable components can receive dynamic data
using props and render UI efficiently.

---

## 🧠 Concepts Learned
- Functional Components
- Props (passing data from parent to child)
- Component Reusability
- JSX
- Folder Structure in React
- Import & Export of Components

---

## 🛠️ Technologies Used
- React.js
- JavaScript (ES6)
- HTML5
- CSS3
